# 기존 서비스 대비 차별점 비교표

> 작성일: 2026-10-24 / 근거: 현대차 공식 페이지, 기사, 앱 스토어 설명(웹 검색 일부 범위). 시장 전수 조사가 아니므로 기획서에는 "확인한 범위에서"로 표기.
> 우리 서비스(가칭 "차량 주치의")는 **기획 단계**이며, 센서 연동은 로드맵(2·3단계)이다.

## 1. 기능 비교

| 항목 | 블루링크 차량 진단 | 리모트 케어(선제케어) | EngineEar AI 등 소리 진단 앱 | **우리 서비스(기획)** |
|---|---|---|---|---|
| 시작 시점 | 경고등 점등 후 | 시스템이 이상 감지 시 | 운전자가 녹음 시작 | **운전자가 "이상하다" 느끼는 순간(경고등 이전 포함)** |
| 입력 방식 | 차량 정보 전송 | 주행 데이터 모니터링 | 마이크 녹음 | **음성 증상 설명 + 차량 데이터 자동 조회** |
| 차 안에서 사용 | 내비 화면 버튼 | 알림/전화 | 폰 앱 (차 안 연동 없음) | **차량 인포테인먼트(Pleos) 앱** |
| 판단 결과 | 상담원이 안내 | 알림 + 조치 안내 | 원인 후보·긴급도(검증 안 됨) | **긴급도 3단계(계속 운행 / 가까운 점검 / 즉시 정차·입고)** |
| 서비스센터 연결 | 상담원 통해 길 안내·예약·견인 | 긴급출동·견인·A/S 연계 | 없음 | **길 안내 + 예약 연결 (데모는 목업)** |
| 간단 부품 교체 안내 | 없음 | 없음 | 없음 | **정차 상태에서 단계별 가이드 (와이퍼·워셔액·전구 등)** |
| 이용 조건 | 블루링크 | 블루링크 가입 고객 한정 | 개인 폰 앱 | 차량 앱 (Pleos App Market 배포 시) |

## 2. 한 줄 차별점
- 기존 서비스는 **경고등 이후 / 시스템 감지 후**가 출발점이다.
- 우리는 **"이상한 느낌" 단계**에서 시작해 **진단 → 센터 연결 → 간단 조치**까지 한 흐름으로 잇는다.

## 3. 현대차 서비스와의 관계 (경쟁 아닌 보완)
- 경고등이 켜지면 → 기존 블루링크 차량 진단으로 연결 (중복 구현하지 않음)
- 경고등이 없지만 이상할 때 → 우리 서비스가 1차 판단
- 입고 필요 판단 시 → 마이현대 정비 예약으로 이어지는 구조 제안

## 4. 단계별 확장 (진단 입력)
| 단계 | 입력 | 상태 |
|---|---|---|
| 1 (공모전 데모) | 음성 증상 + Safety·Tire·Odometer 등 Vehicle SDK 데이터 | 현재 SDK로 구현 가능 |
| 2 (제안) | 외부 진동·소음 센서/OBD를 Plug & Play 액세서리로 연결 | 협의 필요 |
| 3 (제안) | 차량 내장 센서·마이크 데이터 SDK 공개 | 플랫폼 확장 필요 |

## 5. 설계 원칙 (안전)
- 위험 신호(빨간 경고등, 브레이크액 부족 등)는 항상 **정차·입고 안내**
- 결과는 확정 진단이 아닌 **참고 안내**로 표현
- 교체 가이드는 **정차 상태에서만** 표시

## 6. 확인 필요 사항
- 마이크 원본 음성·가속도 센서 접근 가능 여부 → 주최 측 문의
- 에뮬레이터에서 Safety·Tire 데이터가 값을 주는지
- 기존 서비스 최신 기능 (마이현대 앱 직접 확인)
